## Current capacity and independent native inspection

[reporting-capacity/reporting-capacity.json](validation/reporting-capacity/reporting-capacity.json) retains the original exact 100,000×ten-field run, source formulas/blanks, two native pivots, all five aggregates, timings, RSS and binary hashes. Host-specific hardware details are redacted from the public record. `capacity-first.xlsx` and `capacity-resaved.xlsx` are the independently inspected native artifacts. Each passed native graph/openpyxl checks and **960 numeric chart-cache comparisons**. The fixture also validates all report intersections and totals under enabled UDF plus retained-link context. The executed [compact-output rerun](validation/reporting-capacity-computed/reporting-capacity.json) passes the same exact-capacity report calculations: 4,526-ms calculation plus 1,796-ms generation (6,322 ms), 12,726-ms initial creation and 2.67-GiB sampled process-tree peak. This narrower rerun excludes native save/reopen and recovery; those remain baseline evidence. Neither run qualifies the specified reference machine; redacting host-specific details does not broaden the measurements' qualification.

Small native fixtures under `validation/reporting-tdd/fixtures/` cover authored, filtered/multi-measure, grouped and three-chart reports. Their independent inspector validates native source associations and numeric cache points. These parsers provide useful independent evidence; they do not execute Microsoft Excel refresh.

The indexed lookup and single-insertion fixes now have a final selected-capacity GUI input record: **1,000,000 populated data cells**, ten existing-cell edits plus ten new-column insertions, **22.048-ms input-to-paint p95** ([final log](validation/reporting-desktop/final-input.log), [identity](validation/reporting-desktop/final-summary.json)). The prior 73.942-ms failure and narrower 100,000-cell traces are retained.

The visible actual-event-loop report harness retains a source formula across fresh and warm edits, includes final viewport paint, and checks totals plus one-step Undo/Redo and no-op revision/history. The final optimized executables pass initial/fresh/changed-source-current-calculated/unchanged actions in **5,131 / 6,418 / 2,278 / 2,008 ms**, with longest dispatch **43.723 ms**, viewport paints 7–12 ms and sampled publication process-tree peak 2.51 GiB ([final trace](validation/reporting-desktop/final-publication.log), [identities](validation/reporting-desktop/final-summary.json)). The warm path has no workbook/native external links, and the completed shared calculation precedes the warm timer. The earlier private `-O1` UI-object run is retained with its [exact boundary](validation/reporting-desktop/profile-visible-warm-identities.json); this final run uses the all-target Release executables. Offscreen exposure is explicit, and the 16-GiB reference host remains unqualified.

The separate 100,000-cell/20,000-formula/20-sheet calculation fixture takes **609.858 / 557.635 / 561.427 ms** ([final record](validation/reporting-desktop/final-recalculation-100k.json)); the separate 1m/200k-formula/20-sheet calculation stress takes **6,039.809 ms** ([record](validation/reporting-desktop/final-stress-1m.json)). Owned-source transaction preparation is **214.49 ms**, canonicalization **89.86 ms** (`persistence-native-prepare-profile-green.log`); this stage evidence is distinct from whole-action timing. The [quiet latest million-cell native report Undo/Redo measurement](validation/reporting-tdd/persistence-native-history-quiet-final.log) is 126.44/35.54 ms with source allocation retained; the 100-ms Undo goal remains unmet. Report-action dispatch results must not be generalized to every operation.

## Final focused validation and platform boundaries

`worksheet-final-asan.log` completed eleven focused executables with address/undefined sanitizers, `detect_leaks=0` and undefined-behavior halt enabled. `worksheet-reporting-asan.log` / diagnostic and an earlier native-chart attempt retain temporary mixed-layout failures when shared Session headers changed during builds. A complete dependent rebuild passed; those failed attempts are not counted as clean runs. Recovery sanitizer results are separate. Latest cache extraction, instrumented native worker/protocol and actual MainWindow/SnapshotCapture replacement tests pass ASan+UBSan in `analysis-current-cache-{pivot,worker,lifetime}-sanitizer.log`, with `detect_leaks=0`, `abort_on_error=1` and undefined behavior halt enabled. `analysis-current-native-prepared-sanitizer.log` also passes the latest prepared allocation/restoration/rollback cases; `analysis-current-cache-sanitizer-identities.json` records source/object/binary/log hashes and precise instrumentation boundaries. The final optimized application suite passes 82/82 with zero failures in 22.96 seconds (`persistence-performance-final-ctest.log` and `.xml`); `persistence-performance-final-identities.json` records application/worker SHA-256 identities. Final bridge4 and engine2767unit/23doc tests pass in `analysis-{bridge,upstream}-final-typed-parse.log`. The complete-release CPack attempt still refuses (`persistence-performance-final-release-gate.log`).

The first literal-only fast-tab witness did not establish actual cache reuse. A stronger destination-formula witness failed against the prior MainWindow object (`worksheet-tab-cache-context-red.log`), exposing a context stamp inserted into the tools callback rather than the synchronous calculation function. The precise synchronous stamp was corrected, and the complete manual/tab/Show-formulas suite passed against freshly compiled latest MainWindow/grid objects (`worksheet-manual-final-green.log`). The final timing above supersedes the initial literal-only timing.

`worksheet-native-x11-smoke.log` records actual `xcb` success for keyboard completion/pointing/Escape and Qt accessibility editable role, cell address, value and focus. `worksheet-accessibility-offscreen.log` separately passes the accessibility characterization. Existing offscreen-oriented broad fixture attempts (`worksheet-native-x11.log`, `worksheet-formula-native-x11.log`) fail because they assert focus before asynchronous native activation; the focused fixture explicitly waits. Sandbox socket-denied attempts are environment failures, not product regressions.

`worksheet-native-wayland-smoke.log` loads the actual Wayland backend, exposes the test window, then records lack of compositor-granted keyboard focus. Xvfb and weston are unavailable and no packages/settings were changed. Wayland keyboard behavior, screen-reader/AT-SPI operation, global window-manager shortcuts, physical printing, clean installation/upgrade and actual Excel reopen/refresh remain unqualified. The package validator uses private extraction and read-only APT simulation; it must not be described as a performed installation. The actual 0.2.0~dev.1 candidate passes 20 audit commands including staged ELF/runtime/Qt dependencies, app version, launcher/MIME/icons and both worker protocols; APT proposes one upgrade from 0.1.0~dev.2, zero new packages and zero removals. The first path-origin diagnostic was a verifier normalization bug, corrected with focused RED/GREEN; candidate/final package records retain distinct byte checksums. Installation RUNPATH rewriting explains the staged app hash change.

The full frozen compatibility gate remains in force. Forecast/what-if expansion and broad Excel parity remain follow-on work.
