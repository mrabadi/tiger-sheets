## Public integration contracts

`CalculationContext` holds a prepared immutable snapshot, generation, injected evaluator and generation-current predicate. `modelingCommand` and `solveWorkbook` accept an optional context. Trials modify copies of that prepared snapshot; application checks canonical revision and context generation. Standalone modeling still composes enabled read-only VBA functions. Linear qualification uses the native IronCalc AST and conservatively supports arithmetic/SUM dependency graphs; variable-dependent piecewise/nonlinear, dynamic, volatile, circular and unqualified worksheet functions are refused.

`formatCellValue(value, format, locale="en")` uses the pinned native formatter. Decimal display ties now round away from zero after 15-digit noise normalization. Date serials use the supported 1900 system. GETPIVOTDATA has a separate reference-aware callback, independent of VBA enablement. The owned catalog now contains 499 names. Grouped lookups accept generated `Date (year)`/quarter/month aliases, native imported names, and collision suffixes matching the native writer. This slice does not claim complete Excel formula conformance.

`pivotReferenceFormula(book,sheet,row,col)` returns a complete `=GETPIVOTDATA(...)` for a generated measure cell and an empty string for headings/labels/ordinary cells. It quotes captions and worksheet names, fixes the anchor absolutely, retains typed items, and omits the appropriate axis pairs for grand totals. A blank member uses a native empty function argument, preserving its difference from an empty text literal. The worksheet agent separately verified real `=` keyboard entry plus click selection and range fallback.

Report relocation rewrites parsed direct references and defined-name references before clearing any output. A partially intersected range or unqualified workbook-defined reference refuses the whole move. Refresh no-op comparison includes actual cache records, layout, provenance, stale state and output literals; only cache sourceRevision/contextGeneration are ignored. Cross-report source/output dependencies are unsupported and refused when replacing/creating reports.

Reporting proposals expose create/update/refresh/move/delete pivot and create/update/delete PivotChart. Moves use the retained cache and preserve stale state. A no-op refresh returns `status:"unchanged"` without preview/history. `workbook_v1_reports` returns at most 200 cache-free summaries. `workbook_v1_pivot_members` searches all retained typed members, returns at most 200 items/1 MiB, supports offset/query pagination, and reports missing selected members. It retains pointers into the synchronous workbook view rather than copying complete caches. Scalar type/value comparison is explicit because a local C++20 JSON-object ordering probe collapsed distinct typed strings; native filter equality and scalar layout ordering are unchanged.

One member-search test expectation was corrected during GREEN: substring `123` matches `Case123` as well as numeric 123 and text `"123"`; the corrected test asserts all three and preserves the two distinct typed identities. Intermediate compiler/setup errors (a missing `<set>` include and unavailable Qt6 pkg-config metadata) were not counted as behavior RED evidence. The Codex test was linked with the existing CMake-reported Qt include/library paths.

`ReportWorker::start(shared_ptr<const Json>, executable={})` returns immediately. The immutable request contains version1, workbook, definition, retainedLinks and contextGeneration. Optional nativeLinkParts/sourcePath carry only already loaded workbook/external-link XML. Optional allowCachedLinks defaultsfalse. Input serialization and result parsing run on cancellable QThreads; the native child receives private file paths. The child resolves retained/cached sources without refreshing linked files, calculates built-ins/enabled VBA/native pivot lookups, then generates the report. Accepted results retain definition.provenance with link states, diagnostics and cached-value consent.

Only matching version/revision/context successful results reach onResult. Tests cover a foreign revision/context, an oversized sparse result beyond1GiB, private0700 directories/0600 inputs, cleanup, one active job, immediate cancellation feedback and killing a noncooperative child within500ms. The host must perform its own live revision/context check before preview/commit. The default native executable resolves beside the app or in ../libexec.

The100k×10 functional test intentionally permits a longer debug-build deadline. The initial unoptimized30-second attempt timed out; this is retained as diagnostic evidence. An optimized child linked to release archives passed in4.69seconds including the unoptimized parent test launch/parse path on this host. This is not the final warmed performance gate or a reference-machine claim.

`PivotFieldsPane` exposes setDefinition(definition,sheets,fields), definition(), setMemberResults(field,items,total), and apply/source/chart/delete/member-search callbacks. It retains the editable specification and at most200 initial typed members per field, excluding cache/layout. The host searches the complete committed cache and returns at most200 matching members. Hidden selections survive window replacement. New destinations return output.sheet="", newWorksheet=true, newWorksheetName; the host assigns a real sheet identity before generation. All/Explicit filters, blanks/numeric/text distinctions, missing disabled items, source range, existing/new destination, five aggregates, four measures, date grouping and totals are native controls.

`WorkbookSession::prepareTransaction(ownedCapture,operations)` validates and prepares the canonical candidate, history entry, recovery envelope and footprint on a worker. `commitPrepared` only moves the candidate/history/envelope and checks the base revision. `previewPrepared` adopts a prepared candidate; `acceptPrepared` and `discardPrepared` return retired roots for off-thread disposal. `previewView()` is borrowed immutable storage. The host must also bind workbook identity, context generation and job/conversation lifetime. Existing history byte/pruning limits are preserved.

`WorkbookTools::ProposalState` carries the live base revision and a shared immutable expanded operation array. `adoptProposal` requires a matching prepared preview and does not clone its workbook/cache. The desktop resets proposal state after Accept or Discard. The isolated tool child replays the prior operations off-process, calculates built-ins/enabled read-only VBA/GETPIVOTDATA using the captured retained sources, and returns a bounded tool reply plus expanded operations only for authored previews. Read/search/report replies return an empty operations array so they do not retransmit an unchanged cache.

The desktop captures canonical inputs, retained links and prior proposal operations in event-loop slices. Its actual `CodexClient::onToolAsync` launches the child, prepares the candidate off-thread, then checks revision, linked context, workbook recovery identity, proposal identity, job serial and active client state before adopting the preview. Prior calculations are invalidated before replacing a borrowed preview. Stop cancels the child and invalidates pending publication. Heavy captured/returned/retired roots use off-thread deletion, including cancelled and stale jobs. `SnapshotCapture` results now retain that off-thread deletion policy even when callers hold the shared result after completion.

The full deterministic financial workflow passed against the current child: capabilities/read, two cumulative model/chart previews, calculated pending values, search, review/Accept, one Undo/Redo, editable native chart, and XLSX persistence (`analysis-codex-host-financial-green.log`).
