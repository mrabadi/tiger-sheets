## Session foundation

The session exposes `snapshotView`, immutable `captureSnapshot`, binary-search `cellAt`, bounded `lastChange`, and `historyBytes`. Ordinary batched cell/style/clear operations stage coordinate deltas, validate atomically, and merge sorted sheet cells once. Same-topology undo stores changed coordinates and changed metadata; structural history uses JSON patches. The 512 MiB conservative byte budget and 256-entry bound prune old entries, and oversized individual transactions refuse. Parent-owned PivotTable ownership helpers are integrated before/after ordinary edits and for `replace_pivot`/`delete_pivot` transactions. Grid refresh reads live indexed cells and emits changed rectangles; stale calculation caches cannot feed Paste Values.
